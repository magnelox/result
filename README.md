# Sri Sri University Semester Result Portal

A **production-ready, secure, high-performance, responsive Semester Result Portal for Sri Sri University (SSU)**.

This portal is architected to withstand heavy result-publication traffic spikes (**1,000+ concurrent students**) while delivering a **Fast, Simple, Calm, Official, and Reliable** student experience.

---

## 🌟 Key Features

### 1. Student Result Portal
- **Zero Student Login / Account Hassle**: Students simply enter **Registration Number**, **Date of Birth (DD/MM/YYYY)**, and select their **Programme**.
- **Dynamic Programme Dropdown**: Fetched dynamically from database (no hardcoding).
- **Anti-Enumeration Security**: Returns unified generic error messages to prevent student account enumeration.
- **Responsive Mobile Layout**: Choice of desktop tables and mobile cards for uncompromised readability on all screen sizes (Android, iPhone, Desktop).
- **Pre-Generated Grade Card PDFs**: Grade Cards are pre-rendered during admin publish phase and served statically, eliminating server CPU spikes during result traffic spikes.
- **Strict Verification Policy**: No QR codes, barcodes, verification numbers, or external verification links on Grade Cards per official specification.

### 2. Secure Admin Portal (`/admin`)
- **Strong Authentication**: Admin login with HttpOnly secure cookies, bcrypt password hashing, and login rate limiting.
- **Operational Dashboard**: Live counters for total students, imported results, published vs draft records, and latest import logs.
- **CSV Import Engine**: Drag-and-drop file upload, schema validation, warning reports, transactional draft import, bulk Grade Card generation, and final review before publishing.
- **Programme & Course Management**: Full CRUD controls for active programmes and course definitions.
- **Audit Logging**: Comprehensive audit trail recording all admin logins, uploads, imports, grade card generation, and publication state changes.

---

## 🛠️ Stack & Architecture

- **Framework**: Next.js 14 (App Router) + TypeScript
- **Styling**: Tailwind CSS + Custom SSU Design System (Navy `#002147`, Gold `#D4AF37`)
- **Database**: PostgreSQL / SQLite (via Prisma ORM)
- **PDF Engine**: Server-Side PDFKit matching official SSU Grade Card Layout standards
- **Security**: Security Headers, JWT HttpOnly Cookies, Rate Limiter, Anti-Enumeration Response Masking
- **DevOps**: Docker, Docker Compose, Seed Scripts, High-Concurrency Load Testing

## 🚀 Quick Start Guide (Local Development)

### 1. Install Dependencies
```bash
npm install
```

### 2. Push Database Schema & Seed Data
```bash
npx prisma db push
npx prisma db seed
```

Default Admin Credentials generated by seed:
- **Email**: `admin@srisriuniversity.edu.in`
- **Password**: `Admin@SSU2026!`

Sample Student Test Credentials:
- **Registration Number**: `2026MBA001`
- **Date of Birth**: `2002-05-14`
- **Programme**: `MBA`

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) for the Student Portal or [http://localhost:3000/admin](http://localhost:3000/admin) for the Admin Portal.
